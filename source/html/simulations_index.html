Simulations

This project consists of a simulation framework and a collection of simulations written in Scala. Examples include reaction diffusion, fractals, snakes, stocks, dice, fluid flow, and many more.

The easiest way to run a simulation is to download the native installer for your OS from the latest GitHub Release (macOS .dmg, Windows .msi, Linux .deb) and double-click to install.

Or download the zip file and unzip it. Then in the bin directory run one of commands indicated below.
